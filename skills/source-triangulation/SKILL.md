# Source Triangulation

Use this approach when a question depends on current or disputed information.

1. Define the exact claim, geography, and time window.
2. Prefer primary records. Add at least one independent source when practical.
3. Track publication date separately from the date an event occurred.
4. Compare the central claims and identify material agreement or disagreement.
5. Label each conclusion as verified fact, source claim, or inference.
6. Cite the direct page supporting each important statement.
7. State what remains uncertain and what evidence would resolve it.
8. Never invent citations, quotations, dates, or consensus.
